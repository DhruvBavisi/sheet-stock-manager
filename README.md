# StockLog - Sheet Stock Manager

StockLog is an installable Progressive Web App (PWA) that allows you to easily log date, product, and quantity straight to your Google Sheets via Google Apps Script.


## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
